# Сайт доставки еды Star Burger

Это сайт сети ресторанов Star Burger. Здесь можно заказать превосходные бургеры с доставкой на дом.

![скриншот сайта](https://dvmn.org/filer/canonical/1594651635/686/)

Сайт доступен по адресу: [https://star-burgers.com](https://star-burgers.com)

## Как запустить на сервере

Для запуска проекта на боевом сервере (Production) были выполнены следующие шаги:

### 1. Подготовка окружения
- Установлен Python и Node.js (npm).
- Создано виртуальное окружение и установлены зависимости из `requirements.txt`.
- Установлены фронтенд-зависимости через `npm ci`.

### 2. Настройка базы данных и статики
- Проведены миграции Django.
- Собрана статика (collectstatic).
- Собран фронтенд (parcel build).

### 3. Веб-сервер и процессы
- Проект запущен под управлением **Gunicorn**.
- Создан системный юнит **Systemd** для автоматического перезапуска сайта.
- В качестве прокси-сервера настроен **Nginx**.

### 4. Домен и SSL
- Домен `star-burgers.com` привязан к IP сервера через A-записи DNS.
- Установлен **Certbot** для получения SSL-сертификата.
- Настроено автоматическое перенаправление (redirect) с HTTP на HTTPS.

---

### 5. Переменные окружения
```bash
SECRET_KEY = ключ от проекта DJANGO из настроек проекта
ROLLBAR_TOKEN = токен от сайта для мониторинга ошибок 
ROLLBAR_ENVIRONMENT = автоматически выставлен production
DATABASE_URL = параметры подключения к БД
ALLOWED_HOSTS = список разрешенных доменов (star-burger.com)
```

Сайт для мониторинга ошибок [Rollbar](https://rollbar.com)


## Автоматический деплой

Для быстрого обновления сайта на сервере используется скрипт `deploy_star_burger.sh`.

**Что делает скрипт:**
1. Подтягивает актуальную версию кода из репозитория GitHub (`git pull`).
2. Обновляет зависимости Python (`pip install`).
3. Собирает фронтенд (`parcel build`) и статику Django (`collectstatic`).
4. Накатывает новые миграции базы данных.
5. Перезапускает сервис Gunicorn (`systemctl restart`).

**Запуск деплоя одной командой:**
```bash
./deploy_star_burger.sh
```
